# Bài thực hành 01 – Class và Arrow Function

## 1. Nội dung thực hiện

- Khai báo danh sách gồm 5 sinh viên với các thông tin: mã sinh viên, họ tên, tuổi và điểm.
- Sử dụng `class` và `constructor` để xây dựng đối tượng sinh viên.
- Sử dụng hàm mũi tên (Arrow Function) kết hợp với `filter()` để lọc sinh viên có điểm từ 5 trở lên.
- Hiển thị danh sách sinh viên đạt yêu cầu bằng `console.log()`.

## 2. Các bước thực hiện

**Bước 1:** Mở Terminal tại thư mục chứa tập tin `bai01.js`.

**Bước 2:** Nhập lệnh chạy chương trình:

```bash
node BAI1.js
```

**Bước 3:** Quan sát danh sách sinh viên đạt yêu cầu được hiển thị trên Terminal.
