# BÀI THỰC HÀNH 01: CÀI ĐẶT VÀ LÀM QUEN VỚI NODE.JS

## 1. Thông tin sinh viên
- **Họ và tên:** Nguyễn Văn Thưởng
- **Lớp:** CĐ-CNTT18B

## 2. Yêu cầu bài thực hành
- Cài đặt Node.js LTS trên máy tính.
- Kiểm tra phiên bản Node.js và npm bằng lệnh:
  ```bash
  node -v
  npm -v
  ```
- Tạo tập tin `hello.js` và thực thi bằng Node.js.
- Mô tả kết quả thực hiện.

## 3. Kết quả thực hiện và minh chứng

### 3.1. Kiểm tra phiên bản Node.js và npm
```bash
> node -v
v26.13.0

> npm -v
11.20.0
```
- **Nhận xét:** Máy đã cài đặt thành công phiên bản Node.js LTS v26.13.0 và npm v11.20.0.

### 3.2. Chạy tập tin `hello.js`
Lệnh thực thi:
```bash
node hello.js
```

Kết quả hiển thị trên Terminal:
```
=== BÀI THỰC HÀNH 01: LÀM QUEN VỚI NODE.JS ===
Xin chào! Tôi là: Nguyễn Văn Thưởng
Lớp: CĐ-CNTT18B
Phiên bản Node.js: v26.13.0
Chạy ứng dụng Node.js đầu tiên thành công!
```

- **Mô tả kết quả:** Chương trình `hello.js` đã thực thi thành công thông qua Node.js runtime, in ra màn hình thông tin sinh viên và phiên bản Node.js hiện tại.
